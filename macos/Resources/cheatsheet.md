# Markdown cheatsheet

## Blocks

| Markdown | Result |
|---|---|
| `# Title` | Heading level 1 (`##` for 2, `###` for 3) |
| an empty line | New paragraph |
| `- item` | Bulleted list |
| `1. item` | Numbered list |
| `  - item` | Nested list (indent two spaces) |
| `> text` | Quotation |
| ```` ``` ```` | Code block (open and close) |
| `---` | Horizontal rule |
| `\| a \| b \|` | Table row, with `\| --- \| --- \|` under the header |

## Inline

| Markdown | Result |
|---|---|
| `*text*` | Emphasis |
| `**text**` | Strong |
| `` `code` `` | Inline code |
| `[text](url)` | Link |
| `![alt](url)` | Image |
| `\*` | Literal character (escape) |

## Shortcuts

| Keys | Action |
|---|---|
| ⌘B, ⌘I, ⌘\`, ⌘K | Bold, italic, inline code, link |
| ⌘1, ⌘\\, ⌘⇧P | Write, split, preview |
| ⌘⇧O, ⌘F | Jump to heading, find |
| ⌘⇧D | Focus mode (dim other sentences) |
| ⌘⇧Y | Typewriter scrolling (keep cursor centred) |
| ⌃⌘F | Full screen |
| ⌘+ / ⌘- | Larger / smaller text |
