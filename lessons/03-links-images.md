# Links and images

## Links

A link has two parts: the text in square brackets, then the address in round brackets:

Read the [Markdown guide](https://www.markdownguide.org/) if you want more.

You can add a title that shows when the mouse rests on the link: [Loomings](https://loomings.tiagojacinto.eu "The editor you are using").

A bare address becomes a link on its own: https://tiagojacinto.eu

## Reference links

When the same address appears many times, or you want the source to read cleanly, put the address at the bottom of the document and refer to it by name:

Both [this link][guide] and [this other link][guide] point to the same place.

[guide]: https://www.markdownguide.org/

## Images

An image looks like a link with an exclamation mark in front. The text in the square brackets is the *alternative text*, read aloud by screen readers and shown when the image cannot load. Always write it.

![Loomings icon: a letter L on a dark blue tile](https://loomings.tiagojacinto.eu/assets/icon.png)

## Try it

> **Exercise 1.** Add a link to your school or university, with the school's name as the link text.
>
> **Exercise 2.** Turn your link into a reference link, with the address at the bottom of the document.
>
> **Exercise 3.** Find an image on the web, copy its address, and add it here with a good alternative text. Ask yourself: if a friend could not see the picture, what would you tell them?
