# Loomings for the terminal

[Read the construction plan](PLAN.md).

The plan covers a modeless Markdown editor inspired by nano, with references,
CSL styles, HTML/Word/PDF export, lessons and compatible Loomings share links.
It includes the source audit, architecture decisions, terminal requirements,
implementation sequence and release acceptance criteria.

This directory currently contains planning documents. No TUI implementation or
new dependency has been added.
