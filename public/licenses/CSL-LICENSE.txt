# CSL styles and locales

The files in `styles/` and `locales/` come from the Citation Style Language projects. They are licensed under Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0): https://creativecommons.org/licenses/by-sa/3.0/

Sources:

- Styles: https://github.com/citation-style-language/styles
- Locales: https://github.com/citation-style-language/locales

The files are not edited. One file has a new name: `styles/nlm-citation-sequence.csl` is saved as `styles/vancouver.csl`. The author and contributor names stay in each file.

The licence of these files does not change the licence of the Loomings source code.
