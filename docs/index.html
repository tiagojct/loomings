Loomings

A markdown editor in your browser.

v2.0.2

Call me Ishmael. Some years ago — never mind how long precisely — having little or no money in my purse, and nothing particular to interest me on shore, I thought I would sail about a little and see the watery part of the world.

Loomings is a markdown editor that runs in your browser. It opens to a blank page. You write. It stays out of the way. Nothing you type leaves your machine. The first chapter of Moby-Dick is called Loomings, and that is where this came from.

Open Loomings Source on GitHub

What is there

Real markdown in the editor — bold reads bold, headings read heading, code reads code. List lines that continue themselves when you press return, and stop when you press it twice. An outline you can jump to with ⌘P. A focus mode that dims everything outside the sentence under the cursor. Word counts. A word goal if you want one. Find and replace. A split view that shows the source beside the result and keeps the two in step.

For teaching

Six short lessons live under the Learn menu, written to demonstrate themselves: the syntax on the left, what it becomes on the right, an exercise at the end. A cheatsheet sits one keystroke away. And any document can be turned into a link: Export → Copy share link folds the whole text into the address, so a student opens it in their own editor with nothing uploaded anywhere. Hand in with Print / PDF, or send the link back.

Four colours, two moods

Pequod, the parchment and lantern light of this page, is the default. Glauca is frost and one sky blue. Try-Works is cold sea and try-pot fire. Ambergris is near-monochrome grey with a teal that only marks what you can click. Each has a dark and a light side, and will follow the system if you let it.

Where the files go

In Chrome and Edge, to real files on disk, and recent ones are remembered. Elsewhere — Safari, Firefox, an iPad — Save keeps the draft in the browser itself, listed under Documents. Either way the buffer is scratched as you type and offered back if the tab dies. Install it from the browser's menu and it becomes an app that works offline and opens .md files.

What is not

  • No cloud sync.
  • No account.
  • No tracking.
  • No newsletter.
  • No themes marketplace.
  • No AI assistant pestering the margin.
  • No server that sees your text.

The files are your files; they live wherever you put them.

Built with

CodeMirror 6 and markdown-it, served as static files. The source is MIT-licensed. The icon is set in italic Didot. The body in this page is Source Serif. The colours come from a chapter that opens with a man bored of land.
