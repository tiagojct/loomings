Loomings

A markdown editor, for writing and teaching.

v2.0.5

Call me Ishmael. Some years ago — never mind how long precisely — having little or no money in my purse, and nothing particular to interest me on shore, I thought I would sail about a little and see the watery part of the world.

Loomings is a markdown editor that runs in the browser. It opens to a blank page, and stays out of the way while you write on it, hand it to a student, or teach from it with the source next to the result. Nothing you type leaves your machine unless you turn it into a link yourself. The first chapter of Moby-Dick is called Loomings, and that is where the name came from.

Open Loomings Source on GitHub

Write

Real markdown in the editor — bold reads bold, headings read heading, code reads code. Lists continue themselves on return, and stop when you press it twice. An outline you can jump through with ⌘P, a focus mode that dims everything outside the sentence under the cursor, a word goal if you want one. Split shows the source beside the result and keeps the two in step as you scroll either one. Every shortcut is listed in the app itself, one keystroke away (⌘?).

Teach

Six short lessons live under the Learn menu, written to demonstrate themselves: the syntax on the left, what it becomes on the right, an exercise at the end. Any document can be turned into a link — Export → Copy share link folds the whole text into the address, so a student opens it in their own editor with nothing uploaded anywhere. Hand in with Print / PDF, or send the link back.

Four colours, two moods

Pequod — the parchment and lantern light of this page — is the default. Glauca is frost and one sky blue. Try-Works is cold sea and try-pot fire. Ambergris is near-monochrome grey with a teal that only marks what you can click. Each has a dark side and a light side, and follows the system if you let it.

Keep

In Chrome and Edge, real files on disk, with recent ones remembered. Elsewhere — Safari, Firefox, an iPad — Save keeps the draft in the browser itself, listed under Documents. Either way the buffer is scratched as you type and offered back if the tab closes early. Install it from the browser's own menu and it becomes an app that works offline and opens .md files.

What is not

  • No account, no cloud sync.
  • No tracking.
  • No themes marketplace.
  • No AI assistant pestering the margin.
  • No server that sees your text.

The files are your files; they live wherever you put them.

Built with

CodeMirror 6 and markdown-it, served as static files. The source is MIT-licensed. The icon is set in italic Didot. The colours come from a chapter that opens with a man bored of land.
